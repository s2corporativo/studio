Eu não quero uma auditoria que conclua:

> FUNCIONA?

Se sim:

**prove pelo código e teste.**

Se não:

**identifique a causa e corrija.**

Se depende de terceiro:

**identifique exatamente a dependência.**

Se existe apenas no frontend:

**não considere pronta.**

Se existe apenas no README:

**não considere implementada.**

Se existe API mas não há credenciais:

**classifique corretamente.**

Se uma publicação puder acontecer duas vezes:

**corrija.**

Se um usuário puder acessar outra marca:

**trate como crítico.**

Se houver segredo no histórico Git:

**trate como comprometido.**

Se houver conflito SQLite/TiDB:

**determine a arquitetura real e elimine o drift.**

Se a IA criar conteúdo atual sem fonte:

**adicione rastreabilidade.**

Se a IA gerar arte ruim:

**separe geração visual da composição gráfica.**

Se o sistema tiver código de várias versões/agentes:

**consolide sob uma única arquitetura.**
